🟠 Amazon Web Services (AWS) — Research

Brief Overview

Amazon Web Services (AWS) is a cloud platform provided by Amazon that gives individuals and organizations access to computing resources through the internet. Instead of purchasing and maintaining physical servers, users can rent cloud resources when they need them. AWS offers services for applications, databases, storage, networking, security, and other IT requirements. Its resources can also be adjusted depending on how much computing power a project requires.

Global Infrastructure

AWS operates through a worldwide cloud infrastructure divided into **Regions** and **Availability Zones**. A Region represents a geographic area where AWS provides cloud services, while Availability Zones are separate locations within a Region designed to improve system reliability. AWS also uses **Edge Locations** to help deliver content and services closer to users. This infrastructure allows organizations to deploy applications in locations that are suitable for their users and business requirements.

Cloud Management Console

The **AWS Management Console** is a website where users can create, configure, and monitor AWS resources. Through the console, users can manage virtual machines, storage, databases, networks, security settings, and other services. AWS also provides tools such as the **AWS Command Line Interface (CLI)** and **AWS CloudShell**, which allow users to manage resources using commands and scripts.

## Four (4) Core Services

* **Amazon EC2 (Elastic Compute Cloud)** — Provides virtual computers that can be used to run websites, applications, and other workloads. Users can select different configurations depending on their performance requirements.

* **Amazon S3 (Simple Storage Service)** — A cloud storage service used for saving files and objects such as documents, images, videos, backups, and application data.

* **Amazon RDS (Relational Database Service)** — A managed database service that makes it easier to create and maintain relational databases without handling all database administration tasks manually.

  AWS IAM (Identity and Access Management)** — Controls access to AWS resources by allowing administrators to create users, roles, groups, and permissions.

Three (3) Advantages
Flexible Resource Management — AWS allows users to select the amount of computing, storage, and other resources needed for their projects.

  Worldwide Availability — AWS has cloud infrastructure in different parts of the world, giving organizations several choices for deploying their applications.

  Many Cloud Services — AWS provides a large variety of services that can be combined to create complete cloud-based systems.

Typical Enterprise Use Cases

* Running company websites and online applications
* Storing business files, backups, and application data
* Creating databases for business systems
* Supporting online shopping and e-commerce applications
* Developing and testing software applications
* Processing and analyzing large amounts of business data
* Hosting applications that need to support changing numbers of users
