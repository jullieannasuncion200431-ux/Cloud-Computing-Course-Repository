## Discussion Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** has one of the largest selections of cloud services among the three providers. It provides solutions for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other IT requirements. This makes AWS a flexible choice for organizations with different types of projects.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the best option for Microsoft-based environments. Since Azure is developed by Microsoft, it works closely with products such as Windows Server, Microsoft 365, and Microsoft Entra ID. This makes Azure convenient for organizations that already use Microsoft's technology.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform** is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes workloads. Google Cloud provides services such as **Vertex AI** and **Google Kubernetes Engine (GKE)**. These tools can help developers build intelligent applications and manage containerized systems.

### 4. Which cloud platform would you personally choose and why?

For a general-purpose project, I would choose **AWS** because it provides many services that can be used for different types of applications. It also offers flexible resources that can be adjusted when project requirements change. However, I would consider Azure for Microsoft-based systems and GCP for projects focused on AI, machine learning, or Kubernetes.
