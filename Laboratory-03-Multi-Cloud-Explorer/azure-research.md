# 🔵 Microsoft Azure — Research

## Brief Overview

Microsoft Azure is a cloud computing service developed by Microsoft. It allows users and organizations to access computing resources through the internet instead of relying only on physical servers. Azure provides different types of cloud services for hosting applications, storing information, managing databases, building networks, and protecting resources. It is also a useful option for organizations that already use Microsoft technologies.

## Global Infrastructure

Azure has a worldwide cloud infrastructure that is divided into **Regions** and **Availability Zones**. Regions represent different geographic locations where Azure services are available. Availability Zones are separate locations within supported regions that help keep applications and services running if one location experiences a problem. Azure's global infrastructure also helps organizations choose locations based on performance, availability, and data requirements.

## Cloud Management Console

The **Azure Portal** is a web-based management platform where users can create and control Azure resources. It can be used to manage virtual machines, storage accounts, databases, networks, security settings, and other services. Azure also provides **Azure CLI**, **Azure PowerShell**, and **Cloud Shell** for users who prefer command-line tools and automation.

## Four (4) Core Services

* **Azure Virtual Machines** — Provides virtual computers that can run Windows or Linux operating systems. These machines can be configured according to the needs of an application or business system.

* **Azure Blob Storage** — A cloud storage service designed for storing files and other unstructured information such as documents, pictures, videos, and backups.

* **Azure SQL Database** — A managed relational database service that can be used to store and organize structured application data without requiring users to maintain the database server themselves.

* **Microsoft Entra ID** — An identity and access management service used to manage users and control access to applications and cloud resources.

## Three (3) Advantages

* **Good Microsoft Compatibility** — Azure works well with Microsoft-based systems and applications, making it convenient for organizations already using Microsoft products.

* **Hybrid Cloud Support** — Azure provides tools that allow companies to connect and manage resources located both in their own facilities and in the cloud.

* **Enterprise-Friendly Features** — Azure includes management, security, identity, and monitoring features that can help larger organizations manage their IT infrastructure.

## Typical Enterprise Use Cases

* Hosting websites and business applications
* Running Windows and Linux virtual machines
* Storing company documents and backup files
* Managing databases for business applications
* Connecting existing company servers with cloud resources
* Supporting organizations that use Microsoft-based software
* Managing user identities and access to business applications
