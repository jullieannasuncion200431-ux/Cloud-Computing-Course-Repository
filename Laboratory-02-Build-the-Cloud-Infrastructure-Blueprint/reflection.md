 Mission Reflection

1. Which cloud infrastructure component do you think is the most important? Why?

For me, networking is one of the most important cloud infrastructure components because it connects users, servers, applications, and other cloud services. Even if a system has enough computing power and storage, it would not be useful if users and services could not communicate with it properly. A reliable network helps ensure that cloud resources are accessible and can exchange information efficiently.

2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers and cloud workloads. It includes powerful command-line tools that allow cloud engineers to inspect system resources, manage processes, configure networks, and troubleshoot problems. Its open-source nature also makes it widely used in virtual machines, containers, and cloud platforms.

 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of how the infrastructure is planned and configured. It allows engineers to review the design, identify possible problems, and understand the purpose of each component before deployment. Good documentation also makes future maintenance, troubleshooting, and system expansion easier.

 4. What new skills did you learn during this laboratory activity?

During this laboratory activity, I learned how to examine a Linux cloud environment using different terminal commands. I practiced identifying system information such as the operating system, CPU, memory, storage, hostname, and network configuration. I also improved my skills in writing Markdown documentation, organizing files in GitHub, and understanding the roles of different cloud infrastructure components.

5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more structured and informative after completing this mission. I added organized documentation files that contain my infrastructure investigation, cloud component analysis, provider comparison, and reflection. This activity also gave me more experience with creating folders, committing changes, and maintaining a professional technical portfolio.
