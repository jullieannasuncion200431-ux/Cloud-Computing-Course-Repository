# Cloud Provider Comparison

| Infrastructure Component                 | AWS                                                                | Microsoft Azure                                                                      | Google Cloud Platform                                                      |
| ---------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **Compute**                              | Amazon EC2, AWS Lambda, Elastic Beanstalk, Amazon ECS              | Azure Virtual Machines, Azure Functions, App Service, Azure Kubernetes Service (AKS) | Compute Engine, Cloud Run, App Engine, Google Kubernetes Engine (GKE)      |
| **Storage**                              | Amazon S3, Amazon EBS, Amazon EFS                                  | Azure Blob Storage, Azure Managed Disks, Azure Files                                 | Cloud Storage, Persistent Disk, Filestore                                  |
| **Networking**                           | Amazon VPC, Elastic Load Balancing, CloudFront, AWS Direct Connect | Azure Virtual Network, Azure Load Balancer, Azure Front Door, ExpressRoute           | Virtual Private Cloud, Cloud Load Balancing, Cloud CDN, Cloud Interconnect |
| **Identity and Access Management (IAM)** | AWS Identity and Access Management (IAM)                           | Microsoft Entra ID and Azure Role-Based Access Control (RBAC)                        | Cloud Identity and Access Management (IAM)                                 |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS can be considered the provider with the broadest overall selection of cloud services. It provides a large variety of solutions for computing, storage, databases, networking, security, analytics, and other enterprise requirements, giving organizations many options when building cloud environments.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

I would recommend Microsoft Azure because it is designed to work closely with Microsoft's existing technologies. Organizations using Windows Server, Microsoft 365, and Microsoft Entra ID can take advantage of strong integration between their existing systems and Azure services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud Platform is particularly well known for its capabilities in artificial intelligence, machine learning, data processing, and Kubernetes. Its Google Kubernetes Engine (GKE) provides a managed Kubernetes environment, while Google Cloud also provides services and tools for developing and deploying AI and ML applications.

### 4. What similarities did you observe among the three cloud providers?

The three providers offer similar fundamental infrastructure services even though their product names are different. All provide computing resources, several types of storage, networking services, identity and access controls, scalability, security features, and tools for deploying applications in the cloud. This makes it possible for organizations to build comparable cloud architectures on any of the three platforms.
